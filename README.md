# KIRON-XP

**Live Website:** [https://kiron-xp.github.io/KIRON---XP/](https://kiron-xp.github.io/KIRON---XP/)

**KIRON-XP** is a live cloud-synced vault web app accessible from any phone or browser. Open the website link above and sign in with the entry password to access everything synced in real time across devices:

- **2FA Authenticator**: TOTP & HOTP verification codes with instant tap-to-copy.
- **Email Vault**: Saved email addresses, labels, passwords, and notes.
- **KIRON Notes & 100-Row Sheets**: Color-coded notes and live spreadsheet grids.
- **PROFILE Media & APK Vault**: Shared HD photos, full videos, KIRON screenshots, saved numbers, and downloadable `.apk` app packages with gallery thumbnails, titles, and captions.
- **Custom Lock Screen**: 5×6 social app launcher grid, custom wallpapers, and configurable entry password.
